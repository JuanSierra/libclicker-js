useBigInt() → {Builder}

Enables BigInt mode for this generator. When enabled, baseAmount, remainder, and generated amounts are stored as JavaScript BigInt, providing exact arithmetic for values beyond Number.MAX_SAFE_INTEGER (~9×10^15). Uses scaled integer arithmetic internally to handle fractional multipliers (e.g., 1.25).
